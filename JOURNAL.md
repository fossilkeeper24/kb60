Before that, I did some searching around the internet, trying to find which microcontroller is best for a keyboard, and would suit my current level of expertise. I didn't want one that would give me more work than necessary, like for example one that uses BLE, so I settled with the Raspberry Pi Pico. At first I was trying to find a module that had a usb-c port built into it before realising after too long that I could just get a different cable specially for the pi pico and it wouldn't be too much of an inconvenience. I decided that that was better than taking a gamble with some microcontroller that I don't know about nor can find resources for.
